# 스크린샷 안내

이 폴더는 README에서 참조하는 대표 화면 캡처를 담는 자리입니다.
Vision Pro 실기기에서 캡처한 실제 이미지를 아래 파일명으로 이 폴더에 넣어 주세요.

| 파일명 | 캡처할 화면 |
|---|---|
| `control-window.png` | 제어 창 전체 — 요청 입력, 형상 방식 선택, 고른 사물, 컬렉션이 보이는 상태 |
| `restyled-object.png` | 실제 사물(컵·화분 등)을 리디자인한 직후, 안내 라벨과 함께 보이는 몰입 공간 화면 |
| `collection.png` | 저장된 오브젝트 여러 개가 컬렉션 그리드에 보이는 화면 |

## 캡처 방법

- **기기에서 직접**: Vision Pro를 쓴 채 `디지털 크라운 + 상단 버튼`을 동시에 눌러 캡처합니다. 캡처본은 사진 앱에서 Mac으로 옮길 수 있습니다.
- **Xcode에서**: `Window > Devices and Simulators`에서 연결된 기기를 선택하고 화면 캡처 버튼을 누릅니다.
- **Reality Composer Pro 미리보기**: 실기기 캡처가 어렵다면 Xcode의 `RenderPreview` 또는 시뮬레이터 캡처로 대체할 수 있지만, 이 앱은 라이다가 필요해 시뮬레이터에서는 사물 인식 자체가 동작하지 않는다는 점을 감안하세요.

이미지를 넣은 뒤 이 안내 파일은 지워도 됩니다.
